Project photos
--------------
Drop one image per project in this folder (landscape, about 1200 x 900 px,
JPG or WebP, ideally under 300 KB), then add a line to that project in
src/content/projects-current.txt:

  Photo: /assets/projects/hivemind.jpg

The photo then appears on the left of the project on the Home page and the
Projects page. Projects without a Photo line show a "Photo coming" slot.

Only use photos the team has agreed can be public.
